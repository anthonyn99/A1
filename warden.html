Install Warden Launcher

Warden Launcher is the browser extension that opens your Keychain groups from the toolbar — and lets you rearrange the connection cards from there, which syncs straight back here. Browsers don't allow a website to install an extension silently, so this packages it for you and walks you through the one-time load — no Chrome Web Store needed.

  1. Download the extension
    Always packages the latest files straight from GitHub.
  2. Unzip it to a folder you'll keep (e.g. Documents). The extension runs from that folder — don't delete it after.
  3. Open your browser's extensions page (Chrome — can't be opened by a click, so copy & paste it):
    chrome://extensions
    (see Warden/README.md) and loads via about:debugging. Brave / Chrome / Edge / Opera work as-is.
  4. Turn on Developer mode (toggle, top-right of that page).
  5. Click Load unpacked and select the unzipped Warden folder.
  6. Pin Warden Launcher to your toolbar — click it and your Keychain groups appear. Edits you make here sync to it automatically, and a reorder done there syncs back to this page.
  7. Already installed? Warden Launcher doesn't self-update when loaded unpacked. To get the newest version: download again, replace the old Warden folder with the new one (same path), then hit Reload
